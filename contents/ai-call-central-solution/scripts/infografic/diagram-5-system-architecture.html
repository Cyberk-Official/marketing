sequenceDiagram
    autonumber
    participant A as Agent Dashboard
    participant CP as Control Plane (CF Worker)
    participant DB as Neon Postgres DB
    participant W as Session Worker (Node)
    participant R as Retell AI Engine
    participant L as Lead (+65 Mobile)

    A->>CP: 1. Enter lead + mobile + consent
    CP->>DB: 2. Store lead, consent + timestamp
    CP->>CP: 3. Validate DNC & Calling-hours gate
    CP->>W: 4. Trigger callback (< 1 min SLA)
    W->>R: 5. Create outbound call from tenant +65
    R->>L: 6. Dial via BYO SIP over PSTN
    L-->>R: 7. Lead answers phone
    R->>R: 8. Disclose AI + recording, qualify facts
    alt Qualified Lead
        R->>CP: 9a. Check availability & reserve slot
        CP->>DB: Store slot hold (unique constraint)
        R->>L: Offer slots, confirm & book Google Calendar
    else Hot Lead / Advice Question
        R->>A: 9b. Warm transfer to Agent Mobile + Whisper Brief
    else No Answer / Voicemail
        R->>W: 9c. Disconnection reason (voicemail / no answer)
        W->>W: Schedule retry (backoff, in-hours)
    end
    R->>CP: 10. Post-call webhook (transcript & outcome)
    CP->>DB: 11. Persist single lead record
Layer Choice Role & Technical Detail
Voice Orchestration Retell AI Managed STT→LLM→TTS stream engine. Handles call control, barge-in, function calling, transcripts, native warm transfer & AMD voicemail detection.
Telephony Telnyx BYO SIP Dedicated SG +65 Mobile Trunk ($0.0199/min). PSTN termination to Singapore mobiles. Twilio/Didlogic fallback.
Control Plane Cloudflare Workers + Hono Triggers outbound calls, receives Retell/Polar webhooks, calendar tool endpoints, tenant/consent/DNC logic.
Session Worker Persistent Node (Railway) Retell session orchestration, retry scheduler, warm-transfer logic (bypasses CF Workers CPU timeout limits).
Data Store Neon Postgres + Drizzle Leads, consent records, transcripts, outcomes, tenant/seat state, availability/blackout rules & slot holds.
Auth & Billing BetterAuth + Polar Merchant of Record (MoR) per-seat billing + metered overage. In-app minute-cap enforcement via Cloudflare API.
Calendar Sync Google Calendar API freebusy.query for slot availability, events.insert to book slot. Neon DB is source of truth.
