# SKILL SET: Script Maker — Viết Kịch Bản Chi Tiết Cyberk

Skill này hướng dẫn quy trình chuyển hóa **1 Ý tưởng đã được duyệt** (từ bước Brainstorm) thành một **Kịch bản chi tiết (Detail Script 60–90s)** hoàn chỉnh, tuân thủ phễu tâm lý **PAAST** và bộ tiêu chuẩn kỹ thuật **VCL** (*Visual - Content - Logic*).

---

## 📁 Cấu Trúc Thư Mục Skill

```text

```

## 🎯 Mục Tiêu Đợi Xuất File Kịch Bản

Khi thực thi skill này, kịch bản chi tiết sinh ra sẽ được xuất vào thư mục sản xuất dự án:
* **Đường dẫn output dự án:** `scripts/[STT]_[ten_y_tuong].md`
* **Định dạng:** Bảng 2 cột chuẩn sản xuất (Visual & Thao tác kỹ thuật / Audio & Lời thoại).
