# SKILL: Review & Kiểm Duyệt Kịch Bản Cyberk

Thư mục này chứa skill và template hướng dẫn quy trình kiểm duyệt kịch bản 3 lớp trước khi chuyển sang giai đoạn sản xuất (quay dựng).

---

## 📁 Cấu Trúc File

* `review.md`: Skill hướng dẫn kiểm duyệt 3 lớp (Bảo mật, Giá trị cốt lõi Cyberk, Tiêu chuẩn cộng đồng đa nền tảng).
* `template.md`: Template mẫu biên bản kiểm duyệt output tại `contents/[tên-kịch-bản]/reviews/review.md`.
